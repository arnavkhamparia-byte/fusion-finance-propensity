FIELD DEFINITIONS:

borrower_confirmed — true if agent spoke to the actual registered borrower (use voice/name recognition from audio)
third_party_answered — true if someone OTHER than the borrower picked up (detectable from audio: different voice, denial of identity)
third_party_type: Family Member / Friend Or Neighbour / Do Not Know Borrower / Borrower Died (null if borrower answered)

payment_intent — true if customer expressed ANY willingness to pay
  ⚠️ INDEPENDENCE RULE: extract payment_intent SEPARATELY from hardship. A customer can describe
  a hardship (business loss, job loss) AND still say they will pay ("business down hai lekin dunga",
  "thoda time do, kar dunga"). If ANY willingness to pay is voiced, set payment_intent=true even
  when hardship is also present. Do NOT let the hardship suppress the payment signal.
  A partial amount with a relative date counts fully: "Main 2000 bhej deta hoon, teen din baad" → payment_intent=true
intent_strength: high (firm confident tone) / low (hesitant vague) / none
specific_date_mentioned — YYYY-MM-DD ONLY if customer states an ACTUAL CALENDAR DATE they will pay by
  ⚠️ PROMISE-TO-PAY GUARD: agreeing to a senior manager call is NOT a payment date. "Senior se baat
  karunga", "settlement kar lenge", "baad mein dekhte hain" do NOT set this field. Only a concrete
  date ("kal", "15 tarikh", "agle hafte", "sunday ko") counts. If no real date → leave null.
  Resolve relative dates: "N din baad" → current_date+N; range ("do-chaar din baad", "2-4 din mein") → EARLIEST bound (current_date+2)
amount_mentioned — plain numeric string if amount was discussed

sm_call_agreed — true if customer agreed to senior manager callback
sm_call_reason: For Settlement Discussion / For Other Payment Plan / For Further Loan Details / Other / null

callback_requested — true ONLY if borrower gave a SPECIFIC time for Rohini to call back
  Hour-based requests count: "ek ghante baad call karna", "do ghante baad phone karo" → callback_requested=true
callback_datetime — ISO 8601 IST if explicit callback requested
  Relative: "N ghante baad" → current_time+N hours, "N minute baad" → +N minutes, "N din baad" → current_date+N days; range → earliest bound

payment_claimed — true if customer claims payment already made
payment_claimed_type: Full Payment / Partial Payment / Not Sure Of Amount / null

dispute_detected — true if borrower disputes loan existence or validity
dispute_type: Insurance Claim Related / Amount Disputed / Not Availed Loan / Already Cleared The Loan / Fraud Claim / null

hardship_detected — true if borrower disclosed an active crisis
hardship_type: Medical Issue / Job Loss / Business Loss / Agriculture Loss / Death In Family / Other / null
hardship_soft_signal — true if audio cues indicate distress WITHOUT verbal statement:
  Use audio: crying voice, breaking speech, background family crisis sounds, incoherent speech pattern

settlement_negotiated — true if specific amounts were actively discussed between agent and customer
settlement_outcome: Needs Lower Settlement Amount / Did Not Agree For Settlement / Other / null

abrupt_disconnect — true if call ended abruptly (audio cut-off, sudden silence, deliberate hang-up sound)
  Use audio: abrupt end vs gradual farewell exchange
  ⚠️ SHORT-CALL RULE: a very short call (roughly under 25 seconds) that ends with the line cutting
  after only a greeting or one-two words, with NO farewell and NO outcome, IS an abrupt_disconnect=true.
  Do not default short cut-off calls to "ambiguous" — if the line dropped with minimal exchange and
  no natural closing, it was a hang-up. Only set false if there was a clear spoken goodbye/closing.
voicemail_detected — true if call hit automated voicemail system (detect from audio tone/message)
no_answer — phone rang, no answer
busy_signal — busy tone detected
call_failed — telecom failure
invalid_number — telecom unreachable error
disconnected_immediately — connected then dropped with zero exchange

promise_made — true if customer committed to paying by a specific date
  A partial amount + resolvable relative date IS a real promise ("Main 2000 bhej deta hoon, teen din baad" →
  promise_made=true); an amount smaller than the full EMI does NOT weaken the promise.
commitment_strength: strong / moderate / weak / none
tone_shift: improved / neutral / worsened (use audio: tone at start vs end of call)
call_sentiment: positive / negative / neutral
engagement_level: high / medium / low
type_of_customer: Co-operative / Neutral / Non Co-operative
network_quality: Excellent / Good / Poor (use audio quality directly)
conversation_quality: Excellent / Good / Poor
customer_attributes: array of "Soft Spoken" / "Abusive" / "Straight Forward" / "Cunning" / "Fearful" / "Fearless"
compliance_violation — true if AGENT committed violation (threats, harassment, false statements)
compliance_type: Legal / RBI / Police / Other / null
immediate_callback_needed — true if situation warrants same-day follow-up
summary — factual English summary, max 500 characters, no line breaks
